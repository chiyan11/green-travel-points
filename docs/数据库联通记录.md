## 2. 本机环境的两处非默认配置（容易踩坑）

1. **配置文件不在 ProgramData**：服务启动参数是
   `mysqld --defaults-file="D:\coding\mysql\my.ini" MySQL97`，
   因此改端口/字符集要去 `D:\coding\mysql\my.ini`，不在 `C:\ProgramData\MySQL\`。
2. **datadir 在 D 盘**：`D:/coding/mysql/Data`，日志 `DESKTOP-IGAKB82.err` 也在该目录。
   另外 `lower_case_table_names=1`（表名落盘小写）与
   `sql-mode` 含 `ONLY_FULL_GROUP_BY`——P3 写聚合查询时要留意。

## 3. root 怎么连（本机没有明文密码）

`root@localhost` 的密码未知，但 **MySQL Workbench 保存了凭据**，
其自带 `mysqlsh` 用这份凭据可以免密以 root 执行 SQL：

```powershell
$sh = 'D:\coding\mysql\MySQL Workbench\resources\app\shell\bin\mysqlsh.exe'
$env:MYSQLSH_USER_CONFIG_HOME = "$env:APPDATA\MySQL Workbench\mysqlsh"
& $sh --sql --uri "root@localhost:3306" -e "SELECT CURRENT_USER(), VERSION();"
```

这条路径只在本机（有 Workbench 凭据）有效。**组内其他机器用自己的 root 密码**执行
README「1. 数据库准备」里的建库建号 SQL 即可，效果等价。

## 4. 实际执行过的命令

```powershell
# ① 建库 + 建账号（root 身份，经 mysqlsh）
$sql = @"
CREATE DATABASE IF NOT EXISTS green_travel_points DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
CREATE USER IF NOT EXISTS 'greentravel'@'localhost' IDENTIFIED BY 'greentravel';
CREATE USER IF NOT EXISTS 'greentravel'@'127.0.0.1' IDENTIFIED BY 'greentravel';
CREATE USER IF NOT EXISTS 'greentravel'@'%' IDENTIFIED BY 'greentravel';
GRANT ALL PRIVILEGES ON green_travel_points.* TO 'greentravel'@'localhost';
GRANT ALL PRIVILEGES ON green_travel_points.* TO 'greentravel'@'127.0.0.1';
GRANT ALL PRIVILEGES ON green_travel_points.* TO 'greentravel'@'%';
FLUSH PRIVILEGES;
"@
& $sh --sql --uri "root@localhost:3306" -e $sql

# ② 按文件名顺序执行两条 up 迁移（应用账号身份，验证授权可用）
Get-ChildItem db\migrations\*.up.sql | Sort-Object Name | ForEach-Object {
  Get-Content $_.FullName -Raw -Encoding UTF8 |
    mysql -h 127.0.0.1 -P 3306 -u greentravel -pgreentravel --default-character-set=utf8mb4 green_travel_points
}

# ③ 启动后端验就绪探针
. .\scripts\dev-env.ps1                      # 受限环境必须，否则 go 报 Access is denied
cd apps\api; go build -o ..\..\.cache\api-dev.exe .\cmd\server; ..\..\.cache\api-dev.exe
```

## 5. 应用侧怎么配（不需要改代码）

后端从环境变量读 `DB_DSN`，缺省值就是
`greentravel:greentravel@tcp(127.0.0.1:3306)/green_travel_points?parseTime=true&loc=Local&charset=utf8mb4`
（见 `apps/api/internal/config/config.go` 的 `DefaultDatabaseDSN`）。
所以本机装好库之后 **不用建 `.env`** 也能直连；要连别的库再
`Copy-Item .env.example .env` 并改 `DB_DSN`。

`sql.Open` 不建立真实连接（`internal/repo/repo.go`），因此「服务起得来」不代表「库通了」，
**以 `/readyz` 为唯一判据**。
