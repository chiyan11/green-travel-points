## 2. 后台页面与接口的对应

| 页面 | 动作 | 接口 |
| --- | --- | --- |
| `/admin/products` | 列表（状态筛选 + 关键词） | `GET /api/v1/admin/products?status=&keyword=&page=&pageSize=` |
| 同上 | 上架 / 下架（DRAFT/OFFLINE → ONLINE，ONLINE → OFFLINE） | `PATCH /api/v1/admin/products/{id}`（只发 `status`） |
| 同上 | 改库存（展开该商品的 SKU 行，逐个改绝对值） | `PUT /api/v1/admin/skus/{id}/stock` |
| `/admin/products/new` | 新建商品 + 单个「标准款」SKU，默认 DRAFT | `POST /api/v1/admin/products` |
| `/admin/orders` | 全部订单、按状态筛选 | `GET /api/v1/admin/orders?status=` |
| 同上 | 确认收款 / 发货 / 核销完成 | `POST /api/v1/admin/orders/{id}/(confirm|ship|complete)` |

鉴权沿用后端 `RequireAdmin`（`user.role = 'ADMIN'`）；非管理员访问时页面直接显示「当前账号没有管理员权限」，不静默失败。

## 3. 唯一一处后端改动：admin 商品列表补 SKU 明细

**原因**：`GET /api/v1/admin/products` 原来只返回聚合的 `pointsPrice`（最低价）与 `stock`（总库存），没有 `skus[].id`；公开详情接口 `GET /products/{id}` 只查 `status='ONLINE'` 的商品。新建商品默认 DRAFT，于是「改库存」屏拿不到 `skuId`，功能会缺口。

**改动**：

- `apps/api/internal/repo/admin.go`：`ListAllProducts` 在原有分页查询后调 `attachSKUs`，用**一次 `IN` 查询**批量回填 SKU（避免逐条 N+1）。
- `apps/api/internal/httpserver/admin_test.go`：新增 `TestAdminListProductsIncludesSKUs`，断言列表 JSON 的 `items[].skus[].id` 可读。
- `docs/api/README.md`：写明列表返回 `skus` 明细，且 `pointsPrice/stock` 仍是聚合值。

其余 8 个 admin 端点、消费者端接口、数据表结构均未改动。

## 4. 本地账号准备（只动本机库，不改 `db/seed`）

`db/seed/dev_demo.sql` 里两个账号的 `password_hash` 是占位串，格式对不上后端 `sha256$salt$digest` 校验，登不进去。为了让后台与 E2E 能登录，仅在本机 MySQL 里重设了密码：

| 账号 | 身份 | 本机开发密码 |
| --- | --- | --- |
| 13800000002（user 1002） | ADMIN（运营管理员） | `admin123456` |
| 13800000001（user 1001） | CITIZEN（演示用户，余额 1200 分） | `demo123456` |

复现命令（哈希与 `apps/api/internal/httpserver/auth.go` 一致：`sha256( salt + password )`）：

```powershell
# 生成哈希：sha256$hex(salt)$hex(sha256(salt + password))
python -c "import hashlib,os; s=os.urandom(16); print('sha256$'+s.hex()+'$'+hashlib.sha256(s+b'admin123456').hexdigest())"
```

把输出的整串写进库：

```sql
UPDATE user SET password_hash = '<上一步输出>' WHERE id = 1002;   -- admin123456
UPDATE user SET password_hash = '<上一步输出>' WHERE id = 1001;   -- demo123456，重新生成一次
```

> 种子文件未改：新环境若要从零跑 E2E，需先按上表重设这两个账号的密码，或自行注册账号后 `UPDATE user SET role='ADMIN'`。
> 后续若启用「bcrypt 迁移」（AGENTS §11 技术债），这段说明随之失效。

### 5.4 E2E 的副作用与清理

每跑一次会在库里留一件 `E2E环保水杯-<时间戳>` 商品和一笔订单（PENDING/PAID），不影响其他数据。清理：

```sql
DELETE FROM redeem_order WHERE product_name LIKE 'E2E环保水杯-%';
DELETE FROM product_sku WHERE product_id IN (SELECT id FROM product WHERE name LIKE 'E2E环保水杯-%');
DELETE FROM product WHERE name LIKE 'E2E环保水杯-%';
```
