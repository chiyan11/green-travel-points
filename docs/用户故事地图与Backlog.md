### 2.3 地图读法（答辩用）

- 横向看：一条完整旅程“上报 → 算碳 → 发分 → 逛商城 → 兑换 → 履约 → 运营”，对应选题 14 的核心流程。
- 纵向看：同一活动内先做 P0（能跑通），再做 P1（异常/运营），最后做 P2（治理/优化）。
- 切分看：每个 Sprint 取“一个活动列 + 一条端到端切片”，保证迭代末有可工作增量，而不是按层交付。
